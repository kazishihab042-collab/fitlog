# Fitlog

## Project Description

Fitlog is a workout website where users can explore exercises, create workout plans, and save exercises for later.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- DaisyUI
- REST API

## Key Features

1. Users can explore different exercises.
2. Users can add exercises to their workout plan.
3. Users can save exercises for later.
4. Users can mark workouts as completed or remove them.
5. Users can view exercise details, duration, calories, and ratings.
